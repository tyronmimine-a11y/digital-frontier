# Digital Frontier — nouvelle version du prototype

Fichiers statiques :
- `index.html` : accueil responsive
- `boutique.html` : maquette de page produit / préparation de commande
- `styles.css` : design noir, violet sombre et accents rose/violet
- `script.js` : menu mobile et message de prototype non commercial

## Déploiement
Téléversez ces fichiers à la racine du dépôt GitHub `digital-frontier`, en remplaçant les fichiers existants quand GitHub le propose, puis validez avec **Commit changes**. Vercel devrait redéployer le site depuis la branche connectée.

## Important
La page boutique est uniquement une maquette. Elle ne collecte pas de données bancaires et aucun paiement n'est actif. Avant une vente réelle, il faudra intégrer Stripe Checkout, le contenu réel du produit, les prix définitifs, les conditions de vente, la politique de confidentialité et les informations de contact.
