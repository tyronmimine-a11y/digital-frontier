# Site vitrine — Digital Frontier

Prototype de site vitrine responsive en français, avec une direction artistique premium :
- fond noir profond
- accents violets discrets et dégradés violet-rose
- typographie blanche
- visuels abstraits réalisés en CSS/SVG
- sections Accueil, Univers, Projets, Approche et Contact
- menu mobile responsive

## Prévisualiser localement
Ouvrez `index.html` dans un navigateur récent. Une connexion Internet est nécessaire pour charger les polices Google Fonts.

## À personnaliser avant publication
1. Remplacer « Digital Frontier » par le nom définitif de la marque.
2. Remplacer `contact@example.com` par l’adresse de contact réelle.
3. Ajuster les descriptions, les statuts et les visuels des projets.
4. Ajouter les pages légales et les mentions obligatoires.
5. Ajouter un backend et l’intégration Stripe lorsque les ventes seront prêtes. Ne jamais mettre une clé secrète Stripe dans le code frontend ou dans un dépôt public.
6. Configurer le déploiement sur Vercel et, si souhaité, relier un dépôt GitHub.

Ce prototype ne traite pas encore les paiements et ne délivre pas de fichiers payants. Les cartes projets sont présentées comme des aperçus, pas comme des offres à acheter.
